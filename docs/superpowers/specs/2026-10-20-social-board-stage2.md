## 2. Разделы — что внутри

- **Обзор.** Карточки по аккаунтам сегмента: подписчики, Δ вчера/сегодня, спарклайн 7 дней, цель и темп. График накопленного прироста. Топ-3 и анти-3 поста периода по множителю. Лента последних сигналов.
- **Посты.** Таблица с миниатюрой, чипом площадки/языка, форматом, датой, просмотрами, множителем, меткой hit/miss. Фильтры: сегмент, площадка, формат, метка. Карточка поста: снимки по дням, график, комментарии, кнопка «размолоть в черновики».
- **Ответы.** Единая очередь комментариев Threads + Instagram (+ X). Claude предлагает ответ по «Голосу Вадима», ты правишь и жмёшь «Отправить» — уходит через API. Фильтр «требует ответа / вопрос / спам». Статистика: среднее время ответа, доля отвеченных.
- **Сигналы.** Лента событий: пост ×3 к медиане за 24 ч; повторяющийся вопрос; просадка недели; 11-й день поста; токен истекает; цель отстаёт от темпа; стрик прервался. Каждый — с предложенным действием.
- **Черновики.** Из pillar или с нуля: Claude генерирует пакет (сценарии Reels, тексты Threads, карусель, сторис) в твоём голосе; EN-адаптация кнопкой; статусы идея → черновик → готов → запланирован.
- **Расписание.** Календарь недели по площадкам и сегментам. Публикация из дашборда: Threads (текст/фото/видео), Telegram (через бота-админа), Instagram (Reels/карусели/фото/сторис через Content Publishing API; медиа — в Supabase Storage), X (текст/медиа). TikTok/YouTube — после одобрения приложений, до этого «напоминание + готовый файл и текст».
- **Аудитория.** Instagram отдаёт демографию подписчиков (возраст, пол, страны, города) и активность по часам. Threads/Telegram — только динамика. По сегментам отдельно.
- **Источники.** Откуда приходят подписчики: Telegram отдаёт разбивку (уже собирается в `extra`); Instagram — просмотры профиля, клики по ссылке, подписки/отписки. Для сайта vadim.bio и t.me — UTM-ссылки из дашборда с подсчётом переходов.
- **Люди.** Кто чаще всего комментирует, репостит, упоминает — по площадкам. Пометки: клиент / коллега / блогер / тролль. Основа для ответов и для «кого позвать в подкаст».
- **Челленджи.** Стрики (дней подряд с постом), «30 Reels за 30 дней», «100 ответов за неделю». Прогресс-бар, сигнал при срыве.
- **Цели.** Цели месяца по подписчикам (и по просмотрам/заявкам) на каждый аккаунт, редактируются в моменте. Из цели считается темп: нужно +N/день, факт за 7 дней +M/день, прогноз на конец месяца. Из разрыва формируются задачи недели («+1 Reels к плану», «ответить на 12 висящих комментариев», «повторить формат X»). Утренний комментарий Claude — по этим же цифрам.
- **Настройки.** Аккаунты (с сегментом и ролью), токены и сроки, тема, пороги сигналов, получатели отчётов.
