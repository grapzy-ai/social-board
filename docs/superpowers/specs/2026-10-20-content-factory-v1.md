# Спека: Контент-завод v1

Статус: **на подтверждение** (20.10.2026). Цель — деньги через контент быстрее: экспертные ролики с цифрами → кодовое слово → Telegram → консультация → стратегия → Influencio. Завод живёт внутри Social Board; Claude-агенты — его рабочие; публикация только после «Согласовать».

## 1. Конвейер

```
Входящие → Сортировка → Сценарий/Текст → Производство → Согласование → Публикация → Замер (11-й день) → Обучение
```

| Этап | Кто | Где | Выход |
|---|---|---|---|
| Входящие | Вадим (голос, текст, ссылки, скрины — в бота; видео — в Drive `Контент-завод/01 Сырьё видео`) | Telegram-бот + Drive | запись в `inbox_items` |
| Сортировка | агент **Сортировщик** | дашборд | теги: столп, формат, сегмент RU/EN, вид (сырьё / идея / референс / тренд), «куда»: Reels / Threads / TG / сторис / TikTok-life |
| Сценарий/Текст | **Сценарист**, **Копирайтер**, **Редактор** | дашборд → Черновики | сценарий с 3–5 хуками и раскадровкой; тексты Threads/TG/карусели; CTA по ротации |
| Производство | **Дизайнер** (обложки, карусели, карточки из кода по «Визуальному коду v1»), **Монтажёр** (простое — Virale/CapCut-шаблон; сложное — ТЗ человеку) | дашборд + Drive `04 Готовое` | файлы + ТЗ |
| Согласование | Вадим | бот (уведомление) → дашборд (кнопка) | статус `approved` |
| Публикация | **Дистрибьютор** | дашборд → API Threads/IG/TG; TikTok/YouTube — напоминание + файл | ссылка на пост |
| Замер | **Аналитик** (есть) | дашборд | множитель, hit/miss, «кирпичи» |
| Обучение | Аналитик → Сценарист | база знаний | обновлённый банк хуков и форматов раз в неделю |

## 2. Агенты v1 (порядок запуска)

1. **Сортировщик + Сценарист + Копирайтер + Редактор** — день 2. Инструкции: «Голос Вадима», спека v2 (столпы, форматы), «Сторителлинг», «Визуальный код v1», список утверждённых фактов и брендов. Один вход (`inbox_item` или pillar) → один «пакет»: 4 сценария Reels, 5 Threads, 1 карусель (10 слайдов), 3 сторис, 1 TG-пост. EN-адаптация кнопкой (позже).
2. **Дизайнер** — день 2–3. Рендер из кода (как share-карточка): обложка Reels 4:5, слайды карусели 4:5 светлые, карточка Threads, сторис 9:16, кейс-карточка. Шаблоны — из «Визуального кода v1»; Figma не нужна.
3. **Дистрибьютор** — день 3. Расписание недели по площадкам и сегментам; публикация Threads/TG/IG после согласования; схема таблицы = колонки старого контент-плана Вадима (тема, соцсеть, тип, категория, формат, цель, дата, ответственный, статус, пример/тренд, файл, ссылка).
4. **Трендвотчер** — день 3. Источники: Viralmaxing API (виральные ролики ниши Instagram + разборы), YoTrends (TikTok/YouTube тренды и звуки), свои данные (посты ×3 к медиане), Threads keyword search (после разрешения Meta). Дайджест в бот 08:30: 3 быстрых тренда (реакция ≤24 ч, только форматы без съёмки) + 2 долгих (в съёмочный день), у каждого вердикт «снимай / текстом / мимо» и почему. Ключи — только в Vercel: `YOTRENDS_TOKEN`, `VIRALMAXING_TOKEN`.
5. **Монтажёр** — день 4. Сначала проверка Virale на реальном футаже (озвучка + кадры → черновик); если тянет — простые ролики без человека, иначе — генератор ТЗ монтажёру.
6. **Комьюнити** — день 4. Ответы Threads/IG в голосе + комментинг-outreach (согласование обязательно).

Отдельно, без разработки: **воронка кодового слова** в Chatplace под исследование WB/Ozon («пиши ИССЛЕДОВАНИЕ») — настраиваем на этой неделе.

## 3. Данные (минимум)

- `inbox_items`: id, source (bot/drive/manual), kind, text, transcript, media_ref, tags(jsonb), language, status (new → sorted → used → archived), created_at.
- `drafts`: id, inbox_item_id?, pillar_post_id?, type (reel/threads/carousel/story/tg), language, title, body(jsonb: hooks[], script, slides[]), status (idea → draft → ready → approved → scheduled → published), assets(jsonb), scheduled_at, published_post_id.
- `trend_items`: id, source, platform, url, title, metrics(jsonb), horizon (fast/slow), verdict, reason, created_at.

## 4. Перестановка дней дашборда (этап 2)

- **День 2:** Входящие (бот + Drive) · Сортировщик · Черновики с генерацией пакета · публикация в Telegram через бота-админа.
- **День 3:** Расписание · публикация Threads/IG после согласования · Дизайнер (рендер) · Трендвотчер + дайджест.
- **День 4:** Ответы и комментинг · Монтажёр (Virale-проверка, ТЗ) · YouTube/Shorts чтение.
- **День 5:** Сигналы · Цели → задачи недели · недельный отчёт в бот · Аудитория/Источники.

## 5. Неделя 1 — контент (параллельно стройке)

- Pillar №1 в Telegram: «что показало исследование» → пакет.
- Reels: серия «Команда» ×2 (Краснодар, Сочи), «Капри» текст-на-футаже, разбор исследования.
- Карусель 10 слайдов (светлая) по структуре «скелет → хук → … → CTA кодовое слово».
- Threads ежедневно; сторис — «жизнь фаундера» (зрение, ВНЧС, тренер — только сторис/TikTok-life, без экспертного вывода в Reels RU).

## 6. Решения, принятые из ответов Вадима

Лёгкое — в бота, тяжёлое — в Drive · Viralmaxing «Стандарт» помесячно (1 995 ₽ первый месяц, далее 3 990 ₽; энергии 6К/мес ≈ 600 разборов — хватает), «Бизнес» не нужен · YoTrends — бесплатный, пока не подтвердится покрытие RU/MD · Higgsfield — не сейчас · Chatplace — воронки кодового слова · Figma — работаем по экспорту, макеты рендерим кодом.
