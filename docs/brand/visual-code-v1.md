# Визуальный код v1 — из Figma-шаблонов (20.10.2026)

Источник: экспорт файла Figma «Untitled» (37 кадров: 8 обложек YouTube 1920×1080, 27 карточек 1080×1350, 2 сторис 1080×1920). Значения сняты с экспорта; при появлении edit-доступа к Figma уточнить по переменным файла.

## Палитра

| Роль | Значение | Где |
|---|---|---|
| Фуксия (фирменный акцент) | **#D401FE** (в Figma, вероятно, #D400FF) | плашки под заголовком, бейдж VB, фон «манифест-карточек», подсветка последней строки заголовка |
| Чёрный | #000000 / #0D0D0D | фон фото-карточек (фото затемнено градиентом снизу), текст на светлом |
| Светлый фон | **#F6F6F6** (не чистый белый) | текстовые карточки, «спокойные» слайды |
| Белый | #FFFFFF | текст на тёмном и на фуксии |
| Хром/серебро | 3D-объекты (сфера, капля) без заливки, как графический акцент | 1–2 слайда на карусель, не чаще |

Правило: **на одном кадре не больше двух из трёх** — фуксия, чёрный, светлый. Фуксия — либо фон, либо акцент, никогда и то и другое.

## Типографика

- Заголовок: плотный гротеск (в экспорте выглядит как Inter Tight / Helvetica Now Display; название уточнить у дизайнера — до этого в коде используем **Inter Tight Semibold**, открытая лицензия). Крупно, 3–4 строки, выключка влево, межстрочный ~0.95.
- Приём «последняя строка акцентом»: последняя строка заголовка — фуксией (на тёмном/светлом) или на фуксиевой плашке (на фото).
- Рукописный акцент (скриптовый шрифт, как в «хочу блог») — только для эмоциональных/ироничных заголовков, крупно, с выходом за край кадра. Не чаще 1 из 5 постов.
- Цифры — всегда в гротеске крупно («Более 150 000 000 просмотров»), отдельной строкой.

## Постоянные элементы кадра (всегда одни и те же места)

- Чип года `2025`→**`2026`** — левый верхний угол, контурный пилюля.
- Хендл `vadim.bordian ✓` с аватаром — правый верхний угол.
- Бейдж **VB** — фуксиевый квадрат, левая кромка на 2/3 высоты (над заголовком) либо левый нижний угол на текстовых карточках.
- Нумерация серии `0—01` — под чипом года, только в сериях.
- Заголовок — нижняя треть, от левого поля.

## Чего в шаблонах нет и что добавляем (из референсов potapovfx / david_knowsai)

- **Обложка-плашка:** короткий заголовок (3–5 слов) в белой/фуксиевой плашке в верхней трети поверх стоп-кадра с лицом — для сетки Reels, чтобы серия читалась как серия.
- **Последний слайд карусели:** CTA с кодовым словом (`пиши ИССЛЕДОВАНИЕ`), стрелка вниз, без лишнего.
- **Светлая карусель как основной режим** для экспертных листиклов — тёмная оставляется для фото и кейсов. Это ответ на «не агрессивно, на белом, нативно для Instagram».
- Маркер-выделение ключевой фразы в тексте слайда — фуксия 30% прозрачности вместо жёлтого.

## Правила применения

1. Один пост — одна мысль на обложке; не больше 6 слов на фото-обложке.
2. Лицо на обложках Reels в одном ракурсе внутри серии.
3. Экспертные посты — светлые; личные/кейсы — на фото; манифесты — фуксия.
4. Все макеты рендерим из кода дашборда (как share-карточку): шаблон = компонент, данные = заголовок/подзаголовок/фото/номер серии. Figma нужна только для новых шаблонов.
